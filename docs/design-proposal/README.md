# Design proposal (not part of the app)

`index.html` (v2) is a static prototype for client review: home, product, side menu, search, cart, shop states, dark variant; desktop and 390 px phone. `design-notes.html` has type, spacing, colour, dark-mode contrast, motion, video budget and pending items. v1 is in git history (ab07a1c).
Open it in a browser (it reads fonts and logos from `brand/`). Sample content only; gradients stand in
for videos; text in [brackets] is supplied by the client. No website code was changed.
